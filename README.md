# 4. App Concept

## What the App Does

FetchIt connects users with trusted local runners who can complete errands on their behalf.

Users can:

* Send packages

* Buy groceries

* Pick up items

* Deliver documents

* Queue for services

* Pay bills

* Run local errands

* Request transport help

The app focuses on saving time, reducing stress, and improving convenience.

### Ratings & Reviews

Customers rate runners after each task.
